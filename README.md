# היום ומחר - צופן

A personal "today and tomorrow" page for Bar-Ilan Tzofen year 1 students, built from the official schedule (mzb.biu.ac.il/node/5776).
Each visitor answers a few questions; answers stay in their own browser. Nothing is collected.

Built by UniversityOS `kit/build_kit.py`. Campus photo: Bar-Ilan University, CC BY-SA 2.0.
